# 化工产业链投研终端

## 项目概述
一个交互式化工产业链研究网站，覆盖7大原料路线（氟化工、磷化工、硅化工、盐化工、油化工、煤化工、天然气化工），从原料到终端产成品的全链条可视化，并与A股/港股上市公司一一对应。

## 核心功能
1. **产业链全景图** - 可交互的上中下游关系图，点击展开子类
2. **产品价格走势** - 21种产品3年月度价格（2023.01-2025.12）
3. **公司详情页** - 9个Tab：概览/利润趋势/季度明细/财务指标/产能/估值/分产品/商品价格/2026预测
4. **PE估值计算器** - 滑块调PE，实时算三档市值vs当前市值涨跌
5. **价格敏感性分析** - 产品价格变动与利润变动的弹性系数

## 技术栈
- 纯前端：HTML + CSS + JavaScript
- 图表：ECharts 5.5（CDN加载）
- 无需后端，直接浏览器打开即可

## 使用方法
1. 直接用浏览器打开 `site/index.html`
2. 或启动本地服务器：`cd site && python3 -m http.server 8080`
3. 访问 `http://localhost:8080`
